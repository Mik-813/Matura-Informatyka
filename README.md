# Matura Informatyka

A personal collection of notes, shortcuts, and a quick-start workflow for the practical part of the Polish **matura z informatyki** (IT high school exam), covering programming (Python), spreadsheets (Excel), and databases (Access / SQL) in **PyCharm** with a **Sublime** keymap.

## Contents

- **Sublime Keymap Shortcuts** - a cheat sheet of PyCharm shortcuts (set to the Sublime keymap), covering line editing, code folding/collapsing, multi-cursor selection, file navigation, and more.
- **Quick Start Guide** - a step-by-step workflow for setting up the practical exam environment: creating the root folder, opening the project in PyCharm, importing provided data files, and running/testing solutions against sample (`przyklad`) data.
- **Exam Notes** - practical tips accumulated from past exam attempts: formatting results (`wyniki`) correctly, verifying output against sample data, working safely with Excel and Access without losing data, writing and reusing SQL queries in PyCharm, and general exam-day advice.

## Why this repo exists

The goal is to have a single, reliable reference to fall back on during the exam - shortcuts that speed up repetitive editing tasks, a repeatable setup routine so no time is wasted at the start of the exam, and lessons learned from earlier practice runs (mistakes to avoid, safety nets like keeping a backup `.sql` file, etc.).

## Disclaimer

These are personal study notes, not official exam materials. They reflect one student's workflow and preferences (PyCharm + Sublime keymap) and may not apply to every setup or exam session format.
